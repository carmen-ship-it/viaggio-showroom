## Estándar visual (referencia de marca)

| Dimensión | Especificación |
|-----------|----------------|
| **Look** | Cinematic realism · high contrast · warm Santa Cruz daylight · shallow DOF en humanos |
| **UI en pantalla** | Device frames mínimos · UI a 100% brillo · sin scroll janky · easing Apple-style (cubic-bezier 0.4, 0, 0.2, 1) |
| **Tipografía on-screen** | Inter / SF Pro para UI · overlays en Gotham o similar sans premium |
| **Color grade** | Acto 1: desaturado -10% · Actos 2–4: neutro cálido · Acto 5: limpio corporativo · Acto 6: golden hour +10% saturación |
| **Audio bed** | Narrador -3 dBFS · música -18 dBFS bajo VO · SFX handoff a -12 dBFS en 3.3 |

## Leyenda de puntuación

| Score | Significado |
|-------|-------------|
| **Visual Impact (VI)** | Qué tan espectacular se ve en pantalla grande |
| **Effort (EF)** | Costo/tiempo de producción (10 = muy costoso) |
| **Executive WOW (EW)** | Reacción emocional esperada en propietario/gerente boliviano |
| **Prioridad** | **M** = mandatory (sin esto no se estrena) · **O** = optional (eleva calidad; recortable) |

**Fórmula WOW compuesta (para ranking):** `WOW = (VI × 0.35) + (EW × 0.50) + ((10 − EF) × 0.15)`

### Taxonomía — Asset Type (usar solo estos valores)

`Real video` · `Product screenshot` · `Animated UI` · `Motion graphic` · `Executive infographic` · `Drone footage` · `Stock footage` · `AI-generated cinematic scene`

*Escenas compuestas:* listar primario + secundario separados por `+` (ej. `Animated UI + Real video`).

### Taxonomía — Production Method (usar solo estos valores)

`Existing screenshot` · `New UI mockup` · `AI image generation` · `AI video generation` · `Live filming`

*Compuestos permitidos:* `Existing screenshot + Animated UI` · `New UI mockup + Live filming` · etc.
