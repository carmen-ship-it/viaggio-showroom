## Design anchors (match in all exterior assets)

- **Color:** Metallic silver (plateado) with cool highlights
- **Grille:** Large hexagonal mesh with horizontal chrome slats
- **Wheels:** Multi-spoke dark alloy, V-pattern spokes
- **Proportions:** Compact SUV, floating roof, flush door handles, black lower cladding
- **Headlights:** Slim horizontal LED with L-shaped DRL
