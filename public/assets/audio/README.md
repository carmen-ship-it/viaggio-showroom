# Viaggio Showroom Audio Assets

Generated by `npm run generate:audio` (Python + macOS `say`, or bash + ffmpeg).

## Layout

```
ambient/showroom-loop.wav    — continuous showroom pad (loops; 10–15% volume in app)
sfx/nav-tap.wav              — navigation / CTA tap
sfx/card-select.wav          — vehicle card selection
sfx/transition-soft.wav      — screen transition
sfx/success.wav                — financing interest confirm
sfx/qr-reveal.wav              — WhatsApp QR panel
narration/host/host-*.wav      — executive host voice (es-BO)
```

Registry paths use `.mp3`; the audio engine falls back to `.wav` when MP3 is absent.

Re-run with ffmpeg installed for true MP3 output:

```bash
brew install ffmpeg
npm run generate:audio
```

Replace host `.wav` files with studio recordings using the same filenames referenced in `lib/audio/host-narration.ts`.
