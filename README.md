# Viaggio Digital Showroom

Premium interactive digital showroom for **Viaggio Motors Bolivia** — the official **GAC Motor Bolivia** dealership in Santa Cruz.

The showroom acts as a digital salesperson: customers explore, compare, and build confidence with the **GAC GS4 MAX** (and future GAC models) before a human consultant handles financing, test drives, and closing.

## Phase 1 Status

This repository is in **Phase 1: Planning & Documentation**. No application code has been implemented yet.

All product, UX, content, conversion, and technical planning lives in [`docs/`](./docs/).
